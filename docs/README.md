## 🚀 Quick Start

```bash
# Backend (Django)
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver

# Frontend (React/Vite)
cd "sign in lovable"
npm install
npm run dev
```
